## Prompt

Use case: stylized-concept. Asset type: one small pixel-art inventory sprite for a Unity 2D game. Create a single rusty medieval iron helmet, front view, centered, on a truly transparent background. Very simple chunky pixel art built on approximately a 24 by 24 pixel grid, enlarged with sharp square edges, 5 muted flat colors, dark charcoal outline, gray iron and a few rust-brown patches. Match the extremely simple low-resolution protagonist and chunky rusty sword in the reference images; references are style references only, do not draw the character or sword. Rounded dome and a single dark eye slit, no horns, no plumes, no ornaments, no elaborate texture, no gradients, no glow, no ground, no shadow, no text, no UI frame. Helmet should occupy about 80 percent of the square canvas. This must be a clean minimal production game icon, not a detailed illustration.
